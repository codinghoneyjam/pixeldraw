네이티브 UI 공간 배치

현재 egui 패널 선언 순서와 권장 순서를 같은 화면 비율로 비교합니다. 색상 면은 영역 구분용이며 실제 UI 캡처가 아닙니다.

현재 순서에서 폭이 잘리는 가로 패널 전체 폭을 확보한 가로 패널

효과: 작업영역이 정돈되고 상태 정보도 창 전체에서 일정한 위치를 유지합니다.

수정 순서메뉴 → 옵션바 → 상태바 → 툴 레일 → 좌측 패널 → 우측 패널 → 중앙 캔버스 폭 목표좌측 기본 256pt (최소 180), 우측 기본 282pt (최소 200). 반대 패널 폭에 따라 최대 440pt까지 늘어나며, 900pt 창에서도 캔버스 최소 220pt를 우선 남깁니다. 폭 설정은 앱 재시작 간 저장되지 않습니다. 근거 문서네이티브 UI 레이아웃 분석
