기능 비교

Legacy 특징

  • PIL ImageDraw 기반 래스터화
  • JSON 레시피 → RGBA PNG 렌더링
  • 에셋 타입별 전용 생성 스크립트
  • $token 색상 해석 (Python)
  • mirror, transform, erase, blend 연산
  • SQLite 기반 비주얼 스펙
  • AtlasBuilder 클래스 (그리드 패킹)

Current 특징

  • Draw Tool v2 Core Engine 기반 렌더링
  • Transpiler → Session → PixelWriter → PNG
  • 통합 트랜스파일러 + 베이크 스크립트
  • $token 색상 해석 (JavaScript)
  • 다중 레시피 스키마 지원
  • Chunk 기반 32px 정렬 파이프라인
  • 에디터와 동일한 렌더링 경로
